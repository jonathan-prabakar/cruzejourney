# Cruze - Journey assets

Product name: Cruze - Journey.

Tagline: Drive Smarter. Further.

The road-inspired F symbol is retained from the original design as requested by this name-only rebrand.

## Contents
- logos/svg: separate symbol, wordmark, horizontal, stacked and tagline logos in color, white and black. Transparent backgrounds; outlined text in logo SVGs.
- logos/png: corresponding transparent PNG exports at 1600 pixels wide.
- icons: dark, light and monochrome app icons; 1024, 512, 192, 180, 48, 32 and 16 pixel PNGs, SVGs and favicon.ico.
- theme: exact color tokens, CSS gradients and TypeScript colors for Tailwind integration.
- reference: original supplied brand board, retained only as a legacy visual reference; its old product name is superseded by Cruze - Journey.
- prompts: supplied Milestone 1 implementation prompt.

## Recommended usage
Use logo-horizontal-color.svg on dark dashboard headers and symbol-color.svg on sidebars. Use black variants on light backgrounds and white variants for single-color use. Keep aspect ratios and use SVG whenever possible.

These are editable vector interpretations of the supplied raster reference, not pixel-identical original source artwork. The road geometry and lettering are recreated. The photo mockup and UI illustrations remain in the original reference board; they are not supplied as independent production assets.

Copy selected assets to public/brand in your project. Import theme/tokens.css in your global stylesheet. The palette follows the supplied implementation brief, which is authoritative where small labels in the reference differ.
